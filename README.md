# ניווט וקריאת מפה — מדריך אינטראקטיבי לצוער

אתר לימוד אינטראקטיבי בעברית (RTL) לצוערים בעולם קריאת המפה והניווט. אתר סטטי (HTML/CSS/JS ללא תלויות), מיועד ל-GitHub Pages.

## מה יש באתר

1. **יסודות קריאת המפה** — מפה טופוגרפית, קנה מידה, מקרא וצבעים, מדידת מרחק.
2. **תבליט וקווי גובה** — הדמיה אינטראקטיבית של "הצפת" תבליט + הסבר על פסגה, אוכף, שלוחה, ערוץ, קו פרשת מים ומצוק.
3. **מפה אינטראקטיבית של ארץ ישראל** — לחיצה על אזור מציגה את אופי השטח, הגובה, האתגר הניווטי ומאפייני המפה. הצללית נבנתה מקו-גבול גאוגרפי.
4. **דקירת נקודת-ציון (נ״צ)** — מתרגל אינטראקטיבי בשני מצבים: "קרא נ״צ" ו-"דקור נ״צ", ברשת ישראל החדשה (ITM).
5. **מחשבון אזימוט** — מרחק אווירי, אזימוט רשת, אזימוט מגנטי (מצפן) ואזימוט חוזר בין שתי נקודות-ציון.
6. **שלושת הצפונים** — תרשים והסבר על צפון אמיתי/רשת/מגנטי והסטייה המגנטית בישראל.
7. **סדנה יצירתית: תכנון ציר ניווט** — הנחת נקודות ביקורת על לוח ובניית "כרטיס ניווט" מלא (אזימוט, מרחק, אומדן צעדים) עם אפשרות הדפסה/PDF.

## מבנה

```
index.html      דף יחיד עם כל הסעיפים
css/style.css    עיצוב (מוטיב טופוגרפי-צבאי)
js/app.js        כל הלוגיקה האינטראקטיבית + נתוני המפה המוטמעים
assets/map_data.json   נתוני הצללית שנוצרו (לתיעוד; מוטמעים גם ב-app.js)
```

## הרצה מקומית

```bash
python3 -m http.server 8731
# פתחו http://localhost:8731
```
